# Анализ гемоглобина - Docker контейнер

Этот проект содержит R-скрипт для анализа данных пациентов, упакованный в Docker контейнер.

## Требования

- Docker установленный на сервере
- Файл "Пациенты.xlsx" в той же директории, что и Dockerfile

## Сборка и запуск

### 1. Соберите Docker образ:

```bash
docker build -t hemoglobin-analysis .
```

### 2. Запустите контейнер:

```bash
docker run -v $(pwd)/output:/app hemoglobin-analysis
```

### 3. Результаты

После выполнения скрипта в папке `output` на вашем сервере появятся:
- `анализ_гемоглобина.csv` - основной результат анализа
- `глюкоза_по_полу.png` - график распределения глюкозы

## Описание файлов

- `Dockerfile` - конфигурация Docker контейнера
- `script.R` - R скрипт для анализа данных
- `Пациенты.xlsx` - исходные данные пациентов
- `анализ_гемоглобина.csv` - результат работы (создается автоматически)
